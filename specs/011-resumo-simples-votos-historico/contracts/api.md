# API Contract Change: GET /parlamentares/{id}/votos-zil

## Endpoint

`GET /parlamentares/{parlamentar_id}/votos-zil`

## Change

Add `resumo_simples` field to each item in the response array.

## Response Schema (after change)

```json
[
  {
    "votacao_id": "uuid",
    "data": "2026-03-15T14:00:00",
    "descricao": "Requerimento de Urgencia para apreciacao do PL 1523/2026...",
    "categorias_zil": ["ZIL-DIG"],
    "voto": "sim",
    "direcao_esperada": "sim",
    "alinhado": true,
    "proposicao_label": "PL 1523/2026",
    "proposicao_id": "f206d525-0dfa-45cd-87d8-64863fae3d23",
    "resumo_simples": "Cria regras para que sistemas de IA sejam usados de forma mais justa e transparente no Brasil."
  }
]
```

## Field Details

| Field | Type | Nullable | Source | New? |
|-------|------|----------|--------|------|
| `resumo_simples` | `string` | `true` | `Proposicao.resumo_simples` | YES |

## Nullability Rules

- `null` when votacao has no linked proposicao
- `null` when linked proposicao has `contexto_status != "pronto"`
- `null` when `resumo_simples` was not generated by enrichment pipeline
- Non-null string (typically 100-400 chars) when proposicao is enriched

## Backward Compatibility

**Fully backward compatible**. New field is additive and optional. Existing clients that don't read `resumo_simples` are unaffected.
